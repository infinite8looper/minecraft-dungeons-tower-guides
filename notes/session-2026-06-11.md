# Session notes — 2026-06-11

## Status: complete

Built the full tower-guide pipeline from scratch. All 18 tests pass;

## What exists

- `scripts/names.py` — raw-string → wiki-canonical maps for items, bosses,
  enchantments, merchant upgrades. All 136 canonical names verified to have
  `Dungeons:` pages on minecraft.wiki (gotchas: wiki uses "Boneclub" one
  word, "Cool Down", "Tumblebee", "The Starless Night", "The Beginning and
  The End" capital The). Unknown names raise `UnknownName` — build fails
  loudly on new spreadsheet vocabulary.
- `scripts/cycle.py` — current tower = weeks since Mon 2023-05-29, mod 29
  (0→29). Verified vs live sheet: 2026-06-11 → Tower 13. The sheet's hidden
  "Numbers" tab contains this same anchor/29 logic.
- `scripts/fetch_data.py` — Google xlsx export → `data/towers.json`
  (29 towers, 795 floors). `--xlsx` flag for a local file.
- `scripts/fetch_assets.py` — wiki pageimage thumbnails → `assets/icons/`
  (89 item/boss icons + merchant.png from
  `File:DungeonsMiscellaneousSprite Camp Merchant.png` + enchantment-point.png
  from `Dungeons:Enchantment Point`); Monocraft font from the
  `Monocraft-ttf.zip` release asset (the bare .ttf asset no longer exists).
  Wiki API requires a User-Agent header (403 otherwise).
- `scripts/build_pdf.py` — reportlab canvas, page = 1620x2160 px @229 ppi.
  Pages: cover (guide of the week + chips), index, schedule (next 29 weeks,
  the static-PDF substitute for "self-updating cover" — not possible, no JS
  runtime on Remarkable), 29 towers (15 floors/page + notes page).
  All Monocraft (`initialFontName` kills reportlab's Helvetica /F1
  boilerplate). Boss rows: one icon+line per boss. Writing line under each
  floor row. Notes rules 36pt apart (user asked for more vertical space).
- `notes/towers/tower-NN.md` — persistent user notes, auto-created from
  template, rendered into each tower's notes page at build.
- `.github/workflows/weekly-build.yml` — Monday 05:10 UTC rebuild + commit.
- Tests in `tests/test_guides.py` (18, real data / real PDF, no mocks).
